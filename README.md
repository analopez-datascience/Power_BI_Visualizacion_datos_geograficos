# 📊 Argentina Geo Insights – Power BI Analytics Project

## Descripción del proyecto

Este repositorio contiene un proyecto de análisis y visualización de datos desarrollado con **Power BI**, enfocado en la exploración de información geográfica de Argentina mediante dashboards interactivos y visualizaciones orientadas a la toma de decisiones.

El objetivo del proyecto es demostrar competencias en preparación, transformación, modelado y visualización de datos utilizando herramientas propias del ecosistema Power BI.

---

## 🛠️ Tecnologías utilizadas

- Power BI Desktop
- Power Query
- Lenguaje M (Power Query M Language)
- DAX (Data Analysis Expressions)
- Visualizaciones geográficas y mapas interactivos

---

## 🔄 Procesamiento de datos

La preparación de los datos se realizó mediante **Power Query**, utilizando el **lenguaje M**, aplicando tareas como:

- Eliminación de valores nulos.
- Limpieza y estandarización de datos.
- Transformación de columnas.
- Cambio de tipos de datos.
- Creación de campos derivados.
- Optimización de la calidad de los datos antes del modelado.

---

## 📈 Análisis y visualización

Una vez transformados los datos, se desarrollaron diferentes visualizaciones para analizar la distribución geográfica y el comportamiento de las variables estudiadas en Argentina.

Entre los elementos incluidos se encuentran:

- Mapas geográficos interactivos.
- Indicadores KPI.
- Gráficos de barras y columnas.
- Gráficos de tendencias.
- Segmentadores y filtros dinámicos.
- Dashboard ejecutivo para análisis visual.

---

## 🎯 Objetivos del proyecto

- Aplicar procesos ETL con Power Query.
- Demostrar conocimientos de transformación de datos mediante lenguaje M.
- Diseñar modelos de datos para análisis en Power BI.
- Crear dashboards interactivos orientados al negocio.
- Comunicar información de forma visual y efectiva.
